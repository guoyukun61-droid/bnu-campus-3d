# 1.15.0 地图任务面板与连续对话

日期：2026-10-08。用户确认执行 UI 改造，参考 Apple Maps 的紧凑地点卡与连续交互，保留校园视觉而不复制苹果资产。

## 实施范围

- app/explore/index.html：底部输入插槽与新回答提示；整个页面仍只有一个 ask-form。
- app/explore/main.js：输入表单移位、推荐定位/详情分离、上下文返回、消息节点复用、滚动跟随策略、手机看地图收起态。
- app/explore/explore.css：普通面板380px、对话420px，暖纸色半透明面板、较紧凑的列表、统一文字/价格层级、可中断动画、手机底部输入区。
- tests/test_explore_interaction.cjs：用隔离 DOM 执行真实控制器的行为测试；tests/explore-ui.test.mjs 检查尺寸、动效与颜色契约。
- VERSION、CHANGELOG、CLAUDE 和本知识库记录更新。

未修改模型接口、推荐算法、店铺/菜单数据、账号服务、三维几何、密钥和公网部署。未结束持有密钥的进程、未推送 GitHub。已有未提交改动保留。

## 操作方式

1. 点击“吃喝”：默认收起高级筛选，先看地点；所有区域和无坐标记录仍能找到。
2. 点击对话入口：顶部唯一输入框移到对话面板底部，保留未发送草稿、焦点和选区。
3. 推荐卡“在地图看”只移动镜头、高亮位置，不关闭回答；“地点详情”不再次移动镜头，返回按钮回到原回答。
4. 文字更新只修改变化消息，旧回答和不变卡片保持原节点。向上阅读时不会被抢回底部，可以主动“查看新回答”。
5. 手机“看地图”收成底部短面板，保留输入；“继续对话”恢复阅读位置；收起期间的新回复仅提示，不自动弹开。发送新问题主动展开。

## 截图与测试推动的修正

1. 已选中按钮被通用hover浅底覆盖，出现浅底白字：限制普通次级按钮hover规则，不影响选中状态。
2. 价格和“记录价”分散：组合为右侧价格小组。
3. 手机对话过高：增加可恢复的看地图态，不销毁会话或地图。
4. 普通关闭/手机收起后重新打开丢失滚动：恢复时优先保存的scroll，而非刚被面板初始化清零的DOM值。
5. 旧服务明确关闭账号制却仍被fallback require拒绝：仅 enabled===false 放行旧模式，未知或网络错误保持关闭。
6. 关闭面板立即visibility:hidden导致离场动画不可见：用opacity/transform与pointer-events、inert控制，保留退场及权限边界。
