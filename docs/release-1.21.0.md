# 京师智行 1.21.0 · 校园地图与个性化助手

2026-10-09，整合归档版。目标为既有私有仓库 `guoyukun61-droid/bnu-campus-3d`，分支 `main`，版本标签 `v1.21.0`。保持私有属性，不部署网站、不启动Cloudflare、不覆盖历史标签。

## 本版内容

- 地图主导的校园地图册：建筑优先、按分类查看楼内店铺、窗口菜单与分页、目标镜头及可中断漫游。
- 连续对话窗口：提问胶囊、紧凑查询岛、回答摘要、完整阅读；草稿和滚动保留，状态切换动画、键盘和减少动态保护。
- Agent分层：模型适配、工具控制、查询上下文、证据约束回答、关系结果及地图联动；大模型接口可替换。
- 数据读模型：POI/楼层/窗口/菜单身份、包含与空间关系、同类与跨类型关系，保留来源、未知和待核边界。
- 账号隔离、个人聊天与显式偏好、只读模型资源缓存、局部手绘材质试验。运行时数据仍只在本地。

## 上传和排除

Git包含代码、测试、公开来源种子、现有模型/生成素材与开发文档；Release附件提供同版本ZIP与逐文件SHA-256清单。ZIP不进入Git历史。最终附件为 `bnu-campus-v1.21.0-checked.zip` 与对应manifest；保留本地初稿、不覆盖，修正原打包器遗漏无扩展名第三方LICENSE的问题，复核包将许可证列为必需文件。

不包含 `data/`、真实账号/密码哈希/会话、个人聊天、API密钥、`.env`、原始采集响应、原始照片和栅格、运行日志。完整业务数据库未上传，新机器不会自动拥有本机全部店铺菜单。需要跨电脑转移时另做授权的数据备份，不从测试脚本或截图恢复私有记录。

地图含OSM衍生成果（© OpenStreetMap contributors，https://www.openstreetmap.org/copyright），Three.js许可保留在vendor。高分影像/地图衍生与第三方参考截图尚未完成公开再分发核验；此版本仅私有团队归档，不新增公开许可。

## 启动与边界

在项目目录执行 `python app_server.py --port 8793`，打开 `http://127.0.0.1:8793/explore/`。不需要Cloudflare即可本机浏览；端口被占用时先核对归属。

模型通过已有启动器隐藏输入运行时密钥；账号配置见 `docs/accounts-1.14.0.md`。不要把密钥写入README、命令参数或提交。无模型时仍可使用已发布目录和条件查询；新环境缺少私有目录时功能数据范围有限。

未验：真实付费模型全链路、真实手机软键盘和弱网、公网多人测试、地图/影像公开许可。归档版本不宣称完整采集、测绘精度、真实预约或算法优越性。
