# 京师智行团队采集填写教程

适用版本：1.2.1 临时免凭证协作。队员填写网址由管理员发送，审核入口仅在管理员电脑可用。

## 1. 五分钟流程

1. 打开管理员发送的临时网址，选择自己的填写署名：g、kdy、lyx、ljz、ll。无需账号或凭证。此署名不能证明实际填写人，请勿代选他人。
2. 在「采集任务」输入店名或地址。先核对是否已经存在，同名不同分店要看地址和楼层。
3. 点击「领取并补充」。领取有效24小时，只提示分工，不阻止他人纠错。
4. 只填写你能确认的字段，空白表示不修改。填写来源说明、观察日期和时间，必要时上传价目表照片。
5. 「保存草稿」保存在管理员电脑，不只是当前浏览器；「提交审核」交给 g 审核。保持使用同一个浏览器；清除网站Cookie或更换设备后，无法恢复该浏览器私有草稿，联系 g 处理。
6. 在「我的提交」查看状态。退回补充后点击「继续填写」，修改后重新提交。选择相同署名的其他浏览器看不到你的提交。

## 2. 先收什么

- 第一优先：周边餐饮、小吃街的真实营业时间、招牌菜、规格、单品价格和入口位置。
- 第二优先：校内其他商户、疑似重复、缺坐标记录，以及候选更新。
- 食堂：已有官方名称和楼层信息直接沿用；补窗口名称、真实菜单、价目表及现场观察即可。
- 范围：校内各业态；校园边界外扩1公里内餐饮、咖啡和饮品。范围不确定先记录，不能宣称已经纳入推荐。

## 3. 地点、店铺、商品怎么选

地点 POI 是「在哪里」，Shop 是「谁在经营」，Item 是「卖什么」。同一食堂可以有多个真实窗口，同一窗口可以有多道菜。

- 修改地址、入口、楼层、营业时间：选择「地点 / 店铺基本信息」。
- 补某食堂的真实窗口：选择「真实店铺 / 食堂窗口」，关联已有食堂地点。
- 补菜品：选择「真实商品 / 菜品」，关联真实店铺或窗口。模拟窗口不在可选列表。
- 缺少父级时先提交父级，审核批准后刷新页面，再录入子级。

## 4. 示例（以下仅教学，不是现场事实）

假设你在某餐馆价目表看到「牛肉面，小份，18元」：

| 字段 | 填法 |
|---|---|
| 商品名 | 牛肉面 |
| 规格 | 小份 |
| 价格 | 18 |
| 销售渠道 | 根据实际价目表选择堂食/外卖/到店自取 |
| 在售 | 仅在现场确实能购买时选择“观察时在售” |
| 出餐时间 | 未测量就留空，不填默认5分钟 |
| 证据 | 写清观察地点、价目表或官方页面链接，注明优惠限制 |

营业时段示例：`06:30-09:00,11:00-13:00,17:00-19:00`。跨午夜可填 `18:00-02:00`。

排队观察写在「现场备注」：例如「12:15到队尾，12:23点单，12:29取餐；普通工作日」。这是一次观测，不是永久排队时间，暂不自动替代模拟动态接口。

## 5. 坐标与证据

- 经纬度必须同时注明 WGS84 或 BD09。百度坐标不能当成GPS坐标直接用；不知道坐标系就留空。
- 不猜楼栋关联。批准坐标后系统换算模型位置与范围，但不会凭一点位置强行关联建筑。
- 最多5张 JPEG/PNG，每张不超过3MB。上传会移除EXIF/GPS信息，但不会自动消除照片里的可见人脸、手机号、付款码；请事先避开或遮挡。
- 来源按字段保存。不能把百度“人均消费”当作某道菜的价格。
- 食品过敏、清真等限制不能凭印象认定，本轮表单不提供自封认证。

## 6. 常见情况

- 提示「正式记录已改变」：先复制未提交内容，再刷新并重新选择对象；核对最新版本后重填，不能覆盖他人的新记录。
- 提示「同名记录」：交由管理员核对地址/楼层；不是同一分店才能独立批准。
- 断网：未显示保存成功就不要关闭页面，保留表单后重试；记录提交使用幂等ID。
- 草稿仍需来源和时间：不完整的随手笔记先留在自己的记录工具，不拿猜测凑齐必填项。
- 临时网址失效：联系管理员；电脑休眠、断网、服务或隧道停止都会导致不可访问。

## 7. 第一轮试填

团队先选择10家真实商户，每家至少核对名称、位置描述和一项有证据的业务信息。记录遇到的表单困难，由管理员整理修订。自动化测试中的虚构店铺不计入这10家。
