## 1. 实现边界

- 账号固定为 `g / kdy / lyx / ljz / ll`，不开放注册；`g` 为账号管理员。
- 不登录仍能看地图、菜单和使用条件筛选；AI 对话需要登录并完成首次改密。
- AI 对话在服务端按账号保存，换设备后从“我的对话”读取。匿名浏览器历史不自动导入；条件筛选的临时结果不写入 AI 聊天历史。
- 长期偏好只收录用户在“我的账号”表单确认的预算、口味和忌口。可关闭、修改、清空；没有自动从闲聊中提取记忆，也没有向量记忆库。
- 个人偏好是默认条件，不是校园事实。优先级：本次显式条件 → 本对话显式条件 → 启用的长期偏好。关闭长期偏好不会撤销你在当前对话已经明确提出的要求，想完全重新开始请新建对话。
- 每账号每日 20 轮、全队 50 轮，上海时间零点换日。额度以模型请求受理为准，失败/取消/重启中断仍保守占用一轮；同 ID 同内容重试不重复占用。不是人民币金额上限，一轮仍可能包含多次模型调用。
- 管理页只显示账号状态和用量，允许 `g` 停用/启用成员，不提供他人聊天/偏好读取 API。**这不是端到端加密**：控制服务器电脑和磁盘的人仍可能读取私有 JSON。应向队友说明。

## 4. 分层与接口

```text
Three.js 地图（公共资料不变）
  └─ account.js：登录 / 改密 / 偏好 / 账号状态
      └─ app_server.py：精确路由、Host/Origin、请求边界
          └─ account_http.py：Cookie + CSRF + 身份权限
              ├─ accounts.py：独立历史、偏好、请求回执、额度
              └─ 现有 AgentController → 只读校园工具 → 模型适配器
```

| API | 规则 |
|---|---|
| GET `/api/account/me` | 匿名仅返回 enabled/user=null；登录后返回自己及 CSRF |
| POST `/api/account/login` | 精确同源、登录限速；设置 HttpOnly/SameSite Cookie |
| POST `/api/account/password` | 原密码 + 新密码；撤销全部旧会话 |
| POST `/api/account/logout` | 当前会话失效 |
| GET `/api/account/conversations` | 只由服务端登录身份取自己的记录，忽略 URL 中伪造的 user |
| POST `/api/account/conversations/delete` | 只删除自己的指定对话；处理中拒绝 |
| POST `/api/account/preferences` | version 检查；enabled + values 只允许预算/口味/忌口 |
| GET `/api/account/admin/users` | 仅 g，只含账号状态和用量 |
| POST `/api/account/admin/status` | 仅 g，可启停其他成员，不能停用自己 |
| POST `/api/agent/chat`、`/cancel` | 登录 + 首次改密完成 + CSRF；请求/取消按身份隔离 |

公网 Cookie 带 Secure，本机 HTTP 测试不带 Secure；会话最长 8 小时，服务重启需要重新登录。公网还有两小时测试期限与每分钟 30 次 POST 的入口保护。已发到模型的调用不一定能立即取消。

## 5. 数据、密码和恢复

私有文件：`data/life/accounts/accounts.json`；锁文件 `write.lock`、`server.lock`。不在静态资源白名单、已被 `/data/` 的 Git 忽略规则排除。不改旧 SQLite、POI、模型几何和已发布校园数据。

密码采用 PBKDF2-HMAC-SHA256、600,000 次迭代、每密码随机 salt；登录比较使用恒定时间比较。没有明文密码与模型 Key 落盘。此选择使用 Python 标准库，避免为测试版额外安装全局密码库；参考 [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

每次事务：线程锁 → 文件锁 → 读取当前版本 → 原子替换 JSON。账号服务另外持有运行锁，拒绝第二个服务同时使用同一目录。提交前落盘请求/额度，完成后落盘回答，再向页面发完成事件；重启时将 pending 标记为中断而不再请求模型。

忘记密码：在本机进入项目目录运行 `python setup_accounts.py --reset lyx`（使用项目 Python）。显式重置只更新该账号密码和会话版本，不删除聊天。不要把临时密码放在命令行参数里。

备份：停止账号服务后，私下复制 `accounts.json` 到你控制的备份位置；它包含聊天正文，不能上传到公共 GitHub。恢复覆盖当前文件前必须再取得你的批准，并先保留现状。没有本轮自动恢复或覆盖操作。

限制：每人最多 100 个对话、每段最多 100 轮；单文件 JSON 适合五人内测，不是大型生产账号系统。暂无找回邮件、MFA、加密磁盘、审计平台或多实例部署。模型服务会收到必要近期消息（最多 12 条）和生效偏好，不应输入敏感身份信息。

2026-10-08：启动器曾在本地服务configured=true、隧道Registered后，因域名持续NXDOMAIN在120秒结束，导致仅进程内保存的密钥随服务结束而释放。现将公网验证等待改为最多300秒，单次HTTP请求仍10秒、正常校验证书、到期失败仍只关闭自己创建的进程。输出curl错误码，区分DNS问题和模型问题。密钥已配置不代表鉴权或真实AI回答已经成功，首次登录/改密保护不能为自动验收绕过。

“有登录按钮”不等于账号隔离；“有聊天记录”不等于跨设备持久保存；“切换用户名”不等于撤销旧权限。身份必须由服务端判断，前端不能自报归属。额度不能在进程重启后归零，重复请求不能再次付费。个人记忆须可查看和撤回，不用模型猜测替代用户确认。
