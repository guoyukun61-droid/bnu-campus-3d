# 协作采集管理员与接口

## 1.2.1 临时免凭证模式

用户已指定 g、kdy、lyx、ljz、ll 五个署名，要求普通浏览器直接进入，不设置人工邀请凭证。外网端口8790允许选名提交候选；本机 `http://127.0.0.1:8792/` 仅供 g 审核。外网端口不会授予任何名字审核权限。会话由浏览器随机Cookie维持，30天到期；清理Cookie、换浏览器后无法读取先前私有草稿，管理员仍能在本机审核页面看到全部记录。

启动时先由便携 cloudflared Quick Tunnel 获取随机域名，再运行 `python contribution_server.py --team-open --port 8790 --admin-port 8792 --origin https://随机域名.trycloudflare.com`。只把8790转给隧道；不能把8792或既有工作台端口加进去。用户名不是身份验证：公开链接持有者可以选任意署名和提交候选，管理员应核对证据，不能据署名判断责任。真实批量采集前宜定期导出和备份。

临时链接和域名运行时状态保存在私有目录，不写入仓库或版本包。[Cloudflare Quick Tunnel说明](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)

## 运行与边界

团队模式在本机访问 `http://127.0.0.1:8792/` 进行审核；公网网址指向8790，只能填报候选。
推荐使用项目 CLAUDE.md 指定的 Python 3.13。图片处理复用本机已安装 Pillow，坐标处理复用现有 pyproj/shapely/eviltransform；没有新增全局依赖。

服务仅绑定127.0.0.1，静态路由白名单只有 index.html、app.js、style.css。数据目录、工作台接口、源码都不通过该服务暴露。同一协作数据目录使用操作系统文件锁，禁止两个端口同时写入。

### 当前团队访问

1. 用户已授权免凭证临时隧道。便携 cloudflared 放在私有 `data/life/tools/`，从官方 GitHub 下载，Windows 签名有效且 SHA-256 与官方发布资产元数据一致。
2. Quick Tunnel 以 HTTP/2 转发本机8790；随机域名写入私有运行日志。获得域名后以精确 `--origin` 启动填报服务与独立本机审核端口8792。
3. 已验证公网页面、公开署名会话、公开导出拒绝，以及本机审核身份。尚未由队员在手机移动网络执行真实试填，不能将代理端 HTTP 检查说成现场验收。
4. 电脑休眠、断网或隧道重启可能改变链接；重新启动时从新日志读取地址并重启填报服务更新 `--origin`。分享新链接前重新核对公网与本机角色。

Quick Tunnel没有可用性保证，域名可能随重启变化。关机/休眠/断网即不可用，不等于云端常驻部署。[Cloudflare官方说明](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)

## 审核与生效

提交状态：draft → submitted → approved / rejected / needs_info。needs_info允许作者修订后重新提交；approved不允许就地改写，纠错应新建候选修改。

批准前查看旧值、新值、来源、观察时间与附件。同名新增必须先确认独立分店；发生基础版本冲突只能退回重新核对。现阶段疑似重复可以记录处理意见，但不会自动删除或合并实体，实体合并需另行明确方案。

批准操作把审核状态、发布增量、审计版本写进同一个JSON，原子替换。正式 CatalogAdapter 合并此发布增量，旧SQLite仍只读。新增无坐标地点范围为pending；经审核的坐标按现有校园边界+1公里计算范围，范围外对象保留但不推荐。附属区域特殊归属需要后续人工确认，不自动推断。

菜单价格、营业时间等分别附加 field_evidence：来源、观察时间、证据说明、提交ID、审核时间。资料时间不等于实时保证。排队备注暂不变成实时动态值；严格推荐仍会因缺真实动态数据而拒绝，而不是偷偷使用模拟值。

## 接口

所有 `/api/contribute/` 接口（login除外）要求有效浏览器会话。POST还要求精确Origin与会话CSRF头。名字可以被任何持链接者选择，不能证明身份；公开端拿不到管理员会话。

| 方法/路径 | 功能 |
|---|---|
| POST login / logout；GET me | 选择署名、注销、读取浏览器会话及CSRF值 |
| GET catalog / tasks | 已有公开名录、缺口与分工提示 |
| POST claim | 领取地点，24小时分工提示不排他 |
| GET / POST submissions | 当前浏览器会话的提交；本机管理员可查看全部；保存/提交候选 |
| POST attachments；GET attachments/{id} | 图片上传、仅本人或管理员读取 |
| POST review | 仅管理员审核，revision防并发覆盖 |
| GET export | 仅管理员导出记录与审计，不含凭证和图片二进制 |

提交字段：request_id、kind(pois/shops/items)、entity_id、base_revision、patch、evidence、observed_at、attachments、draft；草稿修订增加submission_id与revision。
HTTP 400为输入无效，403为权限/来源失败，409为版本或幂等冲突，429为限流。署名选择20次/分钟、全局写入180次/分钟，使用全局限流而不信任可伪造的代理IP头；适合小团队临时协作，不是高可用公网平台。

## 备份和恢复

停止协作服务后运行 `python -m backend.contribution_admin backup --output 明确且不存在的ZIP绝对路径`。备份包含state.json和attachments，不含成员凭证摘要。私有成员凭证摘要如需备份，应单独受控保存，不与可分享备份混放。

网页导出仅是JSON清单，不是完整附件备份。恢复前先检查ZIP路径安全、schema与关联完整性，在独立目录验证；不得直接覆盖当前目录。恢复涉及数据替换，应获得用户授权后再执行。
